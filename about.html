What this project uses

Everything here runs on AWS Amplify Hosting with no servers to manage. These are the Amplify features set up for this site.

GitHub continuous deployment
Each push to a connected branch triggers a new build and deploy.
Branch environments
main is production, dev is a separate site with its own URL.
Environment variables
SITE_ENV is set per branch and written into the page at build time.
Password protection
The dev site asks for a username and password.
Rewrites and redirects
Unknown paths show a custom 404 page, and /home redirects to the home page.
Custom headers
Security headers are added to every response.
Pull request previews
Each pull request gets a temporary preview URL.
Notifications and monitoring
Build results are emailed, and traffic is visible in the Amplify metrics.
Static HTML and CSS, hosted on AWS Amplify.
